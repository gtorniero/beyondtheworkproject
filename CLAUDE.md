# Regras do projeto

- Respostas em português, curtas e diretas.
- **Hospedagem: o site fica na Cloudflare Pages. NUNCA usar GitHub Pages.** A política do GitHub Pages proíbe uso comercial (vender produtos/serviços), e isso já deu problema uma vez. Não criar workflow, branch `gh-pages`, arquivo `CNAME` para GitHub Pages nem sugerir GitHub Pages.

## Anúncios Meta (Retrozap, Quiddo, SportDNA)

- Tudo que for criado fica PAUSADO.
- Nunca ativar, mudar orçamento ou gastar sem ok explícito do usuário.
- Nunca subir dado de cliente/usuário (Retrozap: nada de mensagens, nomes ou telefones).
- O token da Meta vai só pelo formulário seguro (request_credential, host graph.facebook.com), nunca pelo chat.

## Growth

- Plano, briefings, especificação de medição e IDs das contas em `growth/` (comece por `growth/README.md`).
- Painel: BTW Growth Board (artifact no claude.ai). Os dados da Meta são um retrato que o Claude atualiza toda segunda; as vendas do Stripe são ao vivo.
